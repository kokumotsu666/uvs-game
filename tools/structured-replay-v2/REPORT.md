# 構造化リプレイv2 受け渡し

実装段階は受信、平文変換、圧縮、ロード接続口、照合CLI。指定ブランチの仕様書を参照し、正本フックの不足を INTERFACE.md に列挙した。main、研究ブランチ、公開HTML、PCエンジン、過去の logs_v1 は編集対象外。新しい実装にHTMLエンジン置換は存在しない。旧実験の build.cjs は履歴として維持し、現行HTMLへの切り替えは未実施。

## 変更物

- replay.js はイベントの検証・読取専用コピー、コンパクト形式、旧観測の可逆変換、再生検証と確定を分けるロード接続口。
- normal-log.js は受信値の日本語表示と観戦／相手への非公開情報のマスク。
- compare.cjs はPC正本60局とHTML60局のA/B/C独立照合。
- make_archive.cjs、test.cjs は既存アーカイブとの照合と契約の試験。
- examples は実戦1局分の詳細全文、対応する日本語全文、分離診断、サイズ・検証結果。

## 実測

`node make_archive.cjs ../logs_v1 --verify` と `node test.cjs`。既存の全15組（ミラーを含む）、各2seed×両座席。seedは19070000+a×1000+b×100+i×7。公開版HTMLと旧ログ強化HTMLの60局で、操作列・ターン・勝敗・最終ゾーン不一致0。これは既存対照を再実行したものであり、PC正本との照合件数には含めない。

seed 433775412、74操作の旧v1.9実戦をオフライン再生。終局の旧形式とコンパクト形式、22操作の途中保存から次の判断点、既存詳細観測と診断のオン・オフを比較し一致。全293観測の圧縮・復元は分離診断を含めて可逆。初期状態と終了状態も一致。通常ログ全文175行。

| 同じ試合 | バイト |
|---|---:|
| v1 JSON | 368,759 |
| v2詳細リプレイ全文 | 79,464 |
| 分離した診断 | 4,695 |

詳細本体は約78.5%減。旧観測は文章と粒度の細かい状態差分も保存するため、正本のネイティブ通知を使った試合のサイズは未測定。30回の同一アーカイブの簡易測定ではデコード約3.8 ms／回、エンコード約5.9 ms／回。デコード反復前後のheapUsed差は約3.3 MB。GCとキャッシュを含む単回差で、最大メモリやゲーム中の負荷とは別の測定。

単体試験で、疑似通知の削り名／UID、同名個体、能力辞退、防御なし3理由、相手ドロー名の非表示、診断分離、版不一致・途中で切れたリプレイの拒否、準備失敗時にcommit未呼び出しを確認。比較CLIの契約は人工の1件で確認し、文面差をCだけに計上し、Bの最初の差を検出した。人工データは正本比較として扱わない。

## Claudeへの残件

正本から必要なのは、版固定のルール・カード・デッキ・AI・RNG設定、処理確定イベント、60局のケースID・条件・A/B/Cデータ。現在の `rrlo_v111_start` は別の総当たりで、必要なイベント列・操作列を持つ照合パッケージとして受領していない。v1.11適用、HTMLのコピー／ロードボタン配線、実ブラウザ確認、正本とのA/B/C直接照合は未実施。seed 187367379の実戦操作列も今回のデータには含まれない。
