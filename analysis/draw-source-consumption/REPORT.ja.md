# UVS v1.5 ドロー発生源別の消費量調査

## 1. 対象・結論の範囲

PR #3の`fcbdf073e874501bef8594c23be21e5a74d4edc9`と同じseed・座席・先攻で6,000試合を再実行した。実ドロー呼出しは150,785回、実際に手札へ引いた総枚数は297,037枚。未分類0件、仮想対戦中の実ドロー0件、異常終了0件。全6,000件でPR #3の勝者・理由・ターン・最終状態・既存計測値が一致した。

主要な観測: 柳生の巻物は1試合約2.99–3.26枚（全ドローの12.2–12.6%）、雲雀は約2.15–4.04枚（8.5–13.3%）だった。柳生30枚では枯渇付近の使用と山札切れ敗北に関連がある一方、雲雀は山札6枚以下での巻物使用が全条件0回。巻物を一律に山札切れの主因とする根拠は得られていない。

巻物の実ドロー量と山札切れの関連は記述できるが、使用が敗北の原因だとは断定できない。「巻物を使用しなくても山札切れしたか」は、この計測だけでは分からない。使用しない分岐の対戦は実行していない。

## 7. 柳生・雲雀に関する重点分析

### 柳生・射撃

- 30枚: 巻物は1試合2.987枚、全ドローの12.2%。通常ドローは12.488枚、キャラ能力は総4.126枚／純減1.663枚。山札切れ敗北は15.8% [13.7–18.2]。
- 35枚: 巻物は1試合3.257枚、全ドローの12.6%。通常ドローは12.906枚、キャラ能力は総4.624枚／純減1.734枚。山札切れ敗北は3.7% [2.7–5.1]。
- 40枚: 巻物は1試合3.236枚、全ドローの12.4%。通常ドローは12.930枚、キャラ能力は総4.906枚／純減1.758枚。山札切れ敗北は0.4% [0.2–1.0]。

柳生の能力には「2枚引いて1枚戻す」「戻した枚数だけ引く」が含まれる。Lv4/Lv5のスタンバイ入れ替えは全条件で純減0枚だった。30枚条件で能力の総ドロー4,126枚を純減と見なすと、戻し2,463枚分を過大計上する。巻物の2,987枚は戻しを伴わず、キャラ能力の純減1,663枚より大きい追加消費源だった。

30枚条件では巻物の要求3,169枚に対し実ドローは2,987枚で、82呼出しが要求未満、うち18呼出しは実0枚。ログの要求枚数を使う集計では182枚過大となる。使用直前の山札6枚以下も203回あり、雲雀と異なる枯渇付近の使用が観測された。

30枚条件にはドロー以外にも山札破壊2,869枚、リミットブレイクの使用コスト1,371枚の消費があった。これらを巻物ドローに混ぜず、山札全体の収支からリスクを評価する必要がある。

30枚の使用回数別山札切れ敗北率は 0回: 1.4% [0.4–5.1]（139試合）、1回: 8.6% [6.2–11.8]（394試合）、2回: 26.1% [22.3–30.3]（467試合）。使用が多い群で高い関連があるが、試合の長さも異なる。40枚の敗北は全体でも4件だけで、小標本の群比較に注意する。

### 雲雀・反撃

- 30枚: 巻物は1試合2.152枚、全ドローの8.5%。通常ドローは16.916枚、キャラ能力は総2.369枚／純減2.369枚。山札切れ敗北は61.7% [58.6–64.7]。
- 35枚: 巻物は1試合3.136枚、全ドローの11.0%。通常ドローは18.670枚、キャラ能力は総2.593枚／純減2.593枚。山札切れ敗北は45.0% [41.9–48.1]。
- 40枚: 巻物は1試合4.042枚、全ドローの13.3%。通常ドローは19.773枚、キャラ能力は総2.664枚／純減2.664枚。山札切れ敗北は28.6% [25.9–31.5]。

30枚条件のキャラ能力ドロー2,369枚の内訳はLv2忍転身1,845枚、防御時524枚だった。強制防御ドローだけが能力消費の中心ではなく、牛乳等による再登場も含むLv2忍転身の寄与が大きい。巻物2,152枚は、防御時ドローより大きい一方、通常ドロー16,916枚よりは小さい。

30枚条件で受けた山札破壊は2,889枚で、巻物ドロー2,152枚より多かった。ただし、この量の大小も各要因の勝敗に対する因果効果の比較ではない。

3条件を通じて、山札6枚以下での巻物使用・巻物での山札引き切り・要求未満の巻物ドローはすべて0回だった。現行雲雀CPUが枯渇目前にも巻物を使い続けている挙動は、この範囲では観測されなかった。ただし、以前に引いた分が将来の山札寿命を縮める可能性まで否定するものではない。

30枚条件では巻物使用0回でも133/253試合が山札切れ敗北（52.6% [46.4–58.6]）。また、30→35→40枚で巻物の実ドローは2,152→3,136→4,042枚へ増えた一方、山札切れ敗北は617→450→286件へ減った。巻物量だけで条件間の山札切れ頻度は説明できない。

クロス集計の使用回数と敗北率の関係には、ダメージ量、キャラレベル、防御回数、試合の長さ、相手の山札破壊、CPUの使用判断が交絡する。長い試合では巻物を使う機会も増える。表の関連を因果効果や「巻物を減らせば勝てる」という結論へ置き換えない。

## 8. 計測仕様・検証

- PR #3のruntime.cjs/playをそのまま呼び、PR #3のファイルおよびindex.htmlは変更していない。計測用VMだけでdrawの入口/出口を観測し、委譲先の返値・実際の手札増分・山札減分を照合する。カード/能力・AI・ルールを改変しない。
- VMの元スクリプトに固定の仮想ファイル名を与え、実ドロー呼出しスタックの直接の元ソース行から分類する。元コードの21ドロー呼出し行を静的検査し、実行時の未分類も検出する。合成した未分類呼出しを検出できることも単体検査した（本検証には含めない）。
- 各イベントに発生源、要求/実枚数、ドロー直前の山札残数・通常/無色内訳、引いた通常/無色枚数、ダメージ、ターン、呼出し位置、親サポート名を保存。0枚しか引けない呼出しも記録する。
- PR #3は初手配布後に無色を末尾へ追加する実装。初期手札イベントのbeforeDeck/Normal/Neutralは実配列の値（通常30・無色0）で、pendingInitialNeutralに未挿入の末尾分、effectiveBeforeDeck/Neutralに論理的な35/40枚構成での残数も併記する。初手の実ドローは3条件すべて通常4枚。
- 山札下への戻し、millによる破壊、リミットブレイク使用コスト、ダメージ移動はドローに加算しない。仮想対戦のスタックで実ドローが検出されれば異常として停止する。
- 全試合で「初期枚数＋山札下への戻し−全実ドロー−破壊/使用コスト−ダメージ移動＝最終山札」を独立に検算。発生源/分類別合計と全実ドローの一致、無色ドローのPR #3一致、無色の枚数保存も確認した。
- PR #3全6,000件と勝敗・理由・ターン・最終状態・既存指標が一致。30枚2,000件はさらに前回30枚シミュレーターの照合も通過。予備120件と全12配置の代表seed検査も実施した。
